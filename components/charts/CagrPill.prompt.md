# CagrPill / MarginCapsule / RefChip
Chart annotation atoms. `CagrPill` = grey dashed-arrow growth callout; `MarginCapsule` = outline ratio pill; `RefChip` = black "P. 47" cross-reference.

```jsx
<CagrPill value="9.0%" />
<MarginCapsule value="45.5%" />
<RefChip page={47} />
```
Use CagrPill above/beside a ColumnChart; MarginCapsule on a gross-margin row; RefChip to point at another slide.
