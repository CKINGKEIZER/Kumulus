# GrowthCycle (skeleton)
STR-GROWTH-CYCLE — a flywheel/cycle ring + optional numbered detail rows. Inside `<SlideFrame variant="content">`.

```jsx
<GrowthCycle centerLabel="Compounding flywheel"
  cycle={["Win new installs","Grow installed base","Recurring service","Reinvest in R&D"]}
  detail={[{title:"Land",bullets:["New Flash installs"]},{title:"Expand",bullets:["Service contracts"]}]} />
```
