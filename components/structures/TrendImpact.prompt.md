# TrendImpact (skeleton)
STR-TREND-IMPACT — full-width ComparisonMatrix of market trends × description × impact rating. Inside `<SlideFrame variant="content">`.

```jsx
<TrendImpact matrix={{
  firstColHead:"Market trend",
  columns:[{label:"Description"},{label:"Impact on Company X"}],
  rows:[{label:"Tightening safety regulation", cells:["ATEX enforcement rising", 4]}, {label:"Industrial reshoring", cells:["More EU process plants", 3]}],
}} />
```
