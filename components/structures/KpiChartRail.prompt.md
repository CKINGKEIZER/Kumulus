# KpiChartRail (skeleton)
STR-KPI-CHART-RAIL — a rail of titled chart columns over a full-width panel. Inside `<SlideFrame variant="content">`.

```jsx
<KpiChartRail
  charts={[{title:"Revenue", chart:{data:[...]}},{title:"EBITDA", chart:{mode:"stacked",data:[...]}}]}
  panelTitle="NPS" panel={<Gauge .../>} />
```
