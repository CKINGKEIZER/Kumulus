# Funnel
Tapered stage device (market sizing / pipeline). Narrowing bands with value + label; optional side callouts.

```jsx
<Funnel
  stages={[{label:"TAM",value:"€2.4bn"},{label:"SAM",value:"€480m"},{label:"SOM",value:"€120m"}]}
  callouts={["Total EU explosion-safety spend","Addressable process-safety segment","Realistic 5-yr share"]} />
```
