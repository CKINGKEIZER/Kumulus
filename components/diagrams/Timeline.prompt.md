# Timeline
Company-history timeline: deal-ramp phase-chevron header + year-node line with alternating captions.

```jsx
<Timeline phases={[{label:"Foundation"},{label:"Growth",flex:2}]}
  events={[{year:"'87",text:"Founded",side:"bottom"},{year:"'24",text:"ERP live",side:"top"}]} />
```
For a forward plan use ProcessFlow/roadmap, not Timeline.
