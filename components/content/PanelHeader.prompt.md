# PanelHeader
**Grey** small-caps band that heads a content panel — the house default (colour is reserved for data, NOT headers).

```jsx
<PanelHeader>Diversified customer base</PanelHeader>
<PanelHeader trailing="(FY24A)">Customer concentration by revenue</PanelHeader>
```
tone: "grey" (default) | "plain". Never fill panel headers with deal colour.
