# ColumnHeading
Small-caps heading atop a body column / sub-section, with a rule beneath.

```jsx
<ColumnHeading rule="title">Proven experience</ColumnHeading>
<ColumnHeading rule="separator" align="center">By segment</ColumnHeading>
```
rule: "title" (black 0.5pt) | "separator" (grey 0.25pt) | false.
