Kumulus Layout Patterns

The structural "idea box" — 40 named layout archetypes distilled from all 158 long-template slides (Session 2b). How Kumulus packs dense information with boxes, bars, columns and diagrams. Pair with the semantic taxonomy (what a slide means) and the real-IM canon (how it's written).

Document chrome

Cover LP-COVER
Deal codename + 'Information Memorandum' + month/year, Kumulus mark, confidentiality; optional orange contact chip.
Items: n/a · exemplars: #1
Table of contents LP-TOC
Numbered section rows with page tabs on the right.
Items: 6-9 sections · exemplars: #2
Important notice / disclaimer LP-NOTICE
Dense full-width running text, small type, optional adviser contact block.
Items: 1-2 text blocks · exemplars: #3
Section divider LP-DIVIDER
Oversized ghosted section number/letter + section title, minimal chrome; footer tab expands to the new section.
Items: 1 title · exemplars: #4, #50, #74, #119, #129, #143, #155, #156, #157, #158

Multi-column

Columns under header bars LP-COL-HEADERBAR
2-4 columns, each capped by a navy header bar (white end-knobs), content (bullets/charts/rows) beneath; optional right rail.
Items: 2-4 columns · exemplars: #18, #33, #51, #55, #60, #133, #147, #148
Columns under small-caps headings LP-COL-PLAIN
3-4 columns headed by small-caps + black title-rule; square-bullet copy; evidence row at bottom.
Items: 3-4 columns · exemplars: #99
Card / box grid LP-CARD-GRID
Grid of equal boxes (2x2 up to 4x2), each an icon/heading/short body; flat hairline cards, footer bar.
Items: 4-8 cards · exemplars: #61, #94, #117, #142

KPI / at-a-glance

KPI tiles + combo chart LP-KPI-COMBO
Left KPI tile grid (2x3) + icon bullets; right a stacked-bar + EBITDA%-line combo with CAGR callouts over a donut panel on a grey band. The signature 'at a glance' construction.
Items: 5-6 KPIs + 1-3 charts · exemplars: #5, #45, #81, #114, #121, #135
KPI strip LP-KPI-STRIP
Full-width row of large KPI figures (label + value + period), optional navy band, supporting row beneath.
Items: 4-6 KPIs · exemplars: #7

Charts

Chart + commentary LP-CHART-COMMENTARY
One dominant chart (bar/line/area) with a bulleted commentary rail; period tags; footnote source.
Items: 1 chart + 3-5 bullets · exemplars: #46, #68, #86, #144
Chart dashboard LP-CHART-DASHBOARD
Grid of 3-4 small charts (mini-lines/columns/donuts) + a gauge/legend; scorecard feel.
Items: 3-6 charts · exemplars: #43, #87, #113, #122, #139
Waterfall / bridge LP-WATERFALL
Waterfall or bridge columns (start -> deltas -> end) with connectors and labels; commentary boxes or process footer.
Items: 4-8 bars · exemplars: #9, #38, #100, #123, #145, #147
Donut row LP-DONUT-ROW
Row of donuts (splits/shares) with center labels + legend; often over a KPI strip / navy band.
Items: 2-6 donuts · exemplars: #7, #111
Column chart with trend callouts LP-COLUMN-TREND
Grouped/stacked columns with CAGR brackets and trend line; period tags FYxxA/E.
Items: 5-10 periods · exemplars: #46, #128, #148

Tables

Dense data table LP-DATA-TABLE
Financial/KPI table: row labels + period columns; navy header row; totals/adjustment rows; small type OK.
Items: up to ~15 rows · exemplars: #48, #66, #118
Capability matrix (harvey balls) LP-MATRIX-CHECK
Rows (companies/criteria) x columns (dimensions) filled with harvey-ball / dot ratings; header bars per column group.
Items: 4-10 rows x 3-8 cols · exemplars: #52, #56, #124, #133, #152
Gantt / roadmap table LP-GANTT
Row labels + horizontal phase bars across a time axis; milestone markers.
Items: 3-8 lanes · exemplars: #53, #54, #104, #131, #136
Comparison / feature matrix LP-COMPARE-TABLE
Feature rows x option columns; icon rail; checks/values per cell; positioning takeaway.
Items: 2-4 options · exemplars: #35, #62, #63
Field / description / impact LP-FIELD-DESC-IMPACT
Left vertical navy tab; rows of [field | description | impact-dot]; the recurring qualitative-assessment table.
Items: 4-6 rows · exemplars: #65, #66, #67, #115, #116, #120

Timelines & process

Horizontal timeline LP-TIMELINE-H
Single time axis with milestone nodes above/below; dated callouts; optional dual-sided (icons above and below).
Items: 4-9 milestones · exemplars: #10, #27, #28, #32, #84, #94, #150
Chevron process LP-PROCESS-CHEVRON
Row of chevron/arrow steps (navy) left-to-right; content per step beneath; capability bar footer.
Items: 3-7 steps · exemplars: #26, #29, #30, #42, #93, #126, #151
Process / flow map LP-PROCESS-MAP
Boxes connected by arrows across the canvas (linear or branching); picture/label boxes; may include a rail.
Items: 4-10 nodes · exemplars: #8, #15, #85, #98, #102, #103, #130, #134, #146
Ascending staircase LP-STAIRCASE
Stepped ascending blocks (growth/maturity), each a labelled stage; node diagram beside.
Items: 3-5 steps · exemplars: #108
Stage-gate lists LP-STAGEGATE
Sequential stages, each a numbered vertical list of items; gate markers between.
Items: 3-5 stages · exemplars: #34, #100

Diagrams

Pyramid / segmentation LP-PYRAMID
Layered pyramid (market/segment tiers) as hero, columns of detail beneath or beside.
Items: 3-5 tiers · exemplars: #6, #25, #59, #110
Funnel / cone LP-FUNNEL
Vertical funnel/cone narrowing through stages; counts per stage; panels/table beside (pipeline, M&A funnel).
Items: 3-5 stages · exemplars: #37, #153, #154
Flywheel / circular cycle LP-FLYWHEEL
Circular ring of segments/arrows (repeating cycle) with center label; numbered rail beside.
Items: 3-6 segments · exemplars: #88, #89, #90, #91, #111
Hub and spoke LP-HUB
Central node with radiating connectors to satellites; right rail of icons/labels (ecosystem, one-stop-shop).
Items: 4-8 spokes · exemplars: #70, #80
Venn / overlapping circles LP-VENN
3 overlapping circles (intersection = positioning); text rail; optional node path.
Items: 3 circles · exemplars: #40, #149
2x2 positioning matrix LP-MATRIX-2X2
Two labelled axes forming quadrants; players plotted; company profile table beside.
Items: 4 quadrants · exemplars: #72
Isometric layers LP-ISOMETRIC
Stacked 3D platform layers (architecture/maturity); labels per layer.
Items: 2-4 layers · exemplars: #23
Org / ownership / hierarchy tree LP-ORG-TREE
Top-down box hierarchy with % or roles on connectors (org chart, ownership tree, network).
Items: 5-15 nodes · exemplars: #36, #49, #73, #115, #116, #132
Perspective panels LP-PERSPECTIVE
Trapezoid / receding panels implying progression or depth; icons within; muted end panel.
Items: 3 panels · exemplars: #107, #124
Triangle (3-part) LP-TRIANGLE
Triangle split into 3 labelled parts (or 3 play-triangles) + list panels.
Items: 3 parts · exemplars: #92, #109

Narrative

Investment-highlights arc LP-HERO-ARC
Curved connector / arc with numbered nodes fanning to text rows; 'central idea -> N highlights'.
Items: 4-7 highlights · exemplars: #12
Photo + numbered list LP-PHOTO-LIST
Full-height photo one side; numbered narrative rows the other; curved separator.
Items: 5-9 items · exemplars: #13
Content + big numbers LP-NUMBERED-RIGHT
Icon matrix / content left; oversized 1/2/3 markers with headlines right.
Items: 3 points · exemplars: #24

Geographic

Geographic map + data LP-GEO-MAP
Belgium/Europe choropleth or pin map + data table/legend + icon row; expansion sequence uses several maps.
Items: 1-4 maps · exemplars: #17, #20, #21, #95, #141, #150

Product / screens

Product / screen mockups LP-SCREENS
Device or app-screen mockups (monitor, phone, cards) with process boxes; product/IT demonstration.
Items: 1-4 screens · exemplars: #58, #76, #103

Case study

Case study (Context / Approach / Result) LP-CONTEXT-APPROACH-RESULT
Three chevron-ended header bars (CONTEXT -> APPROACH -> RESULT) each over a content column; warm-band optional; client quote/KPIs.
Items: 3 stages · exemplars: #127
